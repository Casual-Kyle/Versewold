SAFE-01 is the first completed implementation slice. It preserves readable snapshots under the shared roaming app folder, retains 50 revisions per poem/manifest, protects existing content before replacement, and provides an Open backups folder action. It is a bounded saved-version history, not a separate-device backup or a crash-recovery journal. A revision/restore UI follows in SAFE-02. See [backup behavior and manual recovery](backups.md).

The initial update's broader acceptance exercise is to write several poems, reorder them, restart, recover an earlier draft, and export an ordered collection. The export portion depends on OUTPUT-01 and does not block shipping the smaller safety improvements first.
